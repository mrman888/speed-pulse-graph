# Heart Rate Hero

I want a sport tracker so i can track how intense my training was. I want to have a slick input form before my training and after. To input my heart rate at that moment and to measure my reaction speed by clicking on different things on the screen to measure the speed. The using the data to show me graphs. Populate already with mock data
